# Contributing to Building Humane Tech projects

This is the default guide for any repository in the organization without its own CONTRIBUTING.md. A repository's own file wins.

## You do not need to write code

Rating responses, writing scenarios, translating, fixing docs and trying a quickstart and telling us where you got stuck all count. Open an issue or a pull request directly.

## Code

1. Find or open an issue and say what you plan to do.
2. Wait for a maintainer to reply before you start anything large. Small fixes can go straight to a pull request.
3. Keep pull requests focused and reference the issue.

## Response times

We aim to reply to issues and pull requests within 10 business days. If you hear nothing after 20, comment again.

## Licensing of contributions

Contributions come in under the license the repository goes out under. There is no CLA. By opening a pull request you confirm you have the right to submit it under that license, and you name any third-party material and its license in the description.

## Conduct

See the [Code of Conduct](CODE_OF_CONDUCT.md). Concerns go to info@buildinghumanetech.com.
